With a key, calls go straight from your phone's browser to Anthropic using your own key, stored only in this browser. Treat it like a password: use a key with a spending cap if you can, and don't hand this device to anyone else while it's filled in.
Live transcription uses your browser's built-in speech recognition — reliable on Chrome (Android/desktop), unsupported on most iOS browsers, where you can still type key lines manually once a session starts.
